Tóm tắt kiến trúc — Phần Mềm Xem Ảnh

Tài liệu tổng hợp theo mô hình C4 (Context → Container → Component). Ngôn ngữ: tiếng Việt.

1. System Context (C4 Level 1)

Phần tửMô tả

Hệ thốngPhần Mềm Xem Ảnh — ứng dụng desktop PySide6 trên Windows. Điểm vào: viewer_qt.py. Mã chính trong xemanh/, bộ lọc ảnh nữ trong loc_nu.py.

5. Thông số kỹ thuật

  • Hệ điều hành: Windows 7 trở lên.
  • Ngôn ngữ / runtime: Python 3.10+, PySide6 >= 6.6.0.
  • Quản lý dependencies: uv + uv.lock.
  • Layout mã: Phẳng (không src/), không dùng ruff (dùng pyflakes).
  • Đóng gói: PyInstaller onefile + spec lọc DLL xung đột (~115MB).
  • Độ phủ test: C0/C1 >= 80% (hiện tại ~99.9%).
  • Test: Offscreen CI, giả lập model (không tải 430MB thật).
